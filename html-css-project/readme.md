# Makeup by Pedro

A static HTML and CSS website for a fictional makeup brand. It presents the brand, popular products, a smoky-eye makeup tutorial, community information, customer reviews, and contact details.

## Features

- Brand introduction
- Makeup product showcase with descriptions and prices
- Step-by-step smoky-eye tutorial
- Community and customer review sections
- Responsive image sizing
- External stylesheet for typography and layout

## Technologies

- HTML5
- CSS3
- JavaScript is prepared in `script.js`, but no JavaScript is currently used

## Project Files

- `index.html` - Main webpage content
- `style.css` - Page and product styling
- `script.js` - Empty placeholder for future interactive features
- `README.md` - Project documentation

## Run the Website

### Open directly

Open `index.html` in a web browser.

### Use a local server

From the project folder, run:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Image Files

The HTML currently references these image filenames:

- `Makeover.png`
- `Lipstick.png`
- `Palette.png`
- `EyeShadow.png`
- `Foundation.png`
- `Blush.png`
- `BrowGel.png`
- `SmokeyEye.png`

Add the matching PNG files to the project root if they are not already available. If an image is missing, the browser will display a broken-image placeholder.
